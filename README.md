## Our idea 
We took the "MyFirstSensorApp" example from the course and will turn it slowly into ours. We want to create a burger that'll reaction to the phone sensors. We'll have 3 settings. The light (it'll either sleep or be awake), the proximity (he'll get scared if someones too close) and finally the movement (he'll workout avec un accélerateur). As in the first app, the measures will be put on the screen as well.
